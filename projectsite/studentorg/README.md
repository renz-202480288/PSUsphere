
# PSUSphere

## Short Description

PSUSphere is a Django-based web application designed to manage and organize information about students, colleges, academic programs, and student organizations. It provides a centralized platform for managing student and organization-related records.

## List of Features

- Manage college information
- Manage academic programs
- Manage student information
- Manage student organizations
- Manage organization members
- View and manage records through the Django Admin interface
- Organize student and organization data in one system
